API Docs

Implemented API. The backend reads MQTT data and persists sensor readings in SQLite.

MethodEndpointMô tả
POST/api/auth/loginJSON body: identifier and password. Successful login sets an HTTP-only session cookie.
GET/api/auth/meCurrent authenticated account.
GET/api/profileProfile loaded from SQLite users.
GET/api/stateESP8266 status, real sensor samples, and LED states.
GET/api/virtual-sensors/stateCB1, CB2, CB3 latest values and recent graph samples.
GET/api/sensorsFiltered and paginated SQLite rows. Query: type, value, keyword, time, page, pageSize.
GET/api/actionsFiltered and paginated SQLite actions. Query: deviceID, action, status, time, page, pageSize.
POST/api/devices/{deviceID}JSON body: { "state": true } or false. deviceID is led1, led2, or led3.

Ví dụ dữ liệu cảm biến

{
  "id": "00360",
  "sensorID": "DHT01",
  "type": "temperature",
  "value": 28.5,
  "unit": "°C",
  "status": "Normal",
  "time": "2026-10-14T09:15:00+07:00"
}

Ví dụ lệnh thiết bị

{ "action": "ON" }
Sensor history and virtual sensor readings are stored in backend/sensors.sqlite.

Protected API routes require a login. Sessions expire after 12 hours; GET /api/auth/logout clears the session.
