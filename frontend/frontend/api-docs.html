API Docs

Tài liệu demo. Các endpoint bên dưới minh họa API dự kiến, chưa có server xử lý.

MethodEndpointMô tả
GET/api/sensorsDữ liệu cảm biến. Bộ lọc: type, value, from, to.
GET/api/actionsLịch sử thao tác. Bộ lọc: deviceID, action, status, from, to.
GET/api/dashboardChỉ số cảm biến và trạng thái led1–led3.
POST/api/devices/{deviceID}/actionsGửi lệnh ON/OFF đến thiết bị.

Ví dụ dữ liệu cảm biến

{
  "id": "00360",
  "sensorID": "DHT01",
  "type": "temperature",
  "value": 28.5,
  "unit": "°C",
  "status": "Normal",
  "time": "2026-10-14T09:15:00+07:00"
}

Ví dụ lệnh thiết bị

{ "action": "ON" }
Chỉ phục vụ trình bày giao diện và ý tưởng API.
